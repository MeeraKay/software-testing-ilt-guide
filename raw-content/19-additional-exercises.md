To receive your Diploma of Completion, you must complete the following exercises. These exercises are designed to validate your working knowledge of the concepts and skills covered during the training.

Exercise: Academy Training Recommendation
- Create a workflow that receives as input a topic (ex: RPA)
- Goes to UiPath Academy's site https://academy.uipath.com
- Searches for the topic in the "Courses" page
- Opens the first course suggested.
- Create a testcase that tests if the suggestion was correct by checking if the course name contains the topic searched.

Exercise: Hash Check
- You are given an excel file containing the word "UiPath" hashed by multiple hashing methods
- Check using the data driven method if for every hash method, the output matches the one returned by http://www.sha1-online.com/ .
