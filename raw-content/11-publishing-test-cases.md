To publish the test cases that you create in Studio, you must set the test cases as publishable, because both test cases and data-driven test cases are created as drafts by default.

To publish the test cases within all types of Studio projects, perform the following steps:

[INTERACTIVE SCENARIO WALKTHROUGH -- 5 steps, content below]

1 of 5 -- Introduction

Business case:

Imagine you are a Test Automation Engineer working at UiBank. You have created a test case to check the loan status for different variations and combinations like short term, mid term, etc. Now you want to link them to test manager, publish the test case to orchestrator and upload the results directly to Test Manager.

Before you start, make sure you have the following:

- Access to the UiBank web application (opens in a new tab).
- Access to Orchestrator and Test Manager in Automation Cloud.
- Connect the assistant to your Orchestrator instance.

If you haven't done so, go back and complete the data-driven test case guided practice.

Ready to start?
[START button]

2 of 5 -- Step 1: Set your test case as publishable

To publish your test cases, select it - right click and select "Set as publishable" option.

Note: you can select multiple test cases together and set them as publishable at once.

3 of 5 -- Step 2: Publish the test cases

Publish the test cases to the orchestrator by clicking on the Publish button on the ribbon.

4 of 5 -- Step 3: Publish the test case

Add the project name and the version that you would like to publish as.

5 of 5 -- Nice work!

You have successfully linked the test case to test manager, published the test case to the orchestrator and also uploaded the execution results to Test Manager.

[START AGAIN button]

To publish to Orchestrator, ensure your Robot or Assistant is connected.
