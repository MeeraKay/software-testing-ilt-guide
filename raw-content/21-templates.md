Test case templates

Use test case templates as base models for your test cases. For example, you can create a template with data variations to be reused on different tests. You can create test case templates for Test Automation projects, including other file types such as Global Exception Handler. Note: for other projects (e.g. Process Automation), you can create workflow templates.

Restrictions

- The templates are specific to the project type and the language that is used to create it.
- The templates cannot be converted to workflows, compiled, or published.

Extract file as template

1. Open your test case in Studio.
2. In the Project panel, right-click it and select Extract as template.
3. You test case is now stored in Project > Templates. You can copy and paste or move it back to your testing folder.

Test Case Templates Advantages

- Consistency: Test case templates ensure uniformity across all the test cases. This makes it easier to understand and execute them and also maintains a standard for evaluation.
- Efficiency: Templates save time and effort by providing a predefined structure for creating test cases. This process reduces the risk of missing out on essential test case components.
- Thoroughness: They guide the tester through all the necessary elements of a test case, ensuring that no detail is overlooked.
