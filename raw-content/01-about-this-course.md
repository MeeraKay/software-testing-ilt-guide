Learning Objectives

By the end of this course you will:

1

Get familiar with Test Manager capabilities and Agentic features

2

Work with testing artifacts: requirements, test cases, test set and test executions

3

Create automated test cases in low-code and coded approaches

4

Apply data-driven testing concepts in test automation by creating, managing, and utilizing test data.

5

Publish and execute automated and manual test cases using Test Manager

6

Apply best practices in test automation development
