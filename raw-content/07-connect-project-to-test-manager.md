Exercise: Let's convert a Manual to Automated Test Case

To complete the integration with Studio, you need to configure the Test Manager Settings.

Open Studio and then open the downloaded project.

In the Design ribbon, navigate to Test Manager > Test Manager Settings.

Go to Test Manager Configuration and enter your Test Manager URL.

Provide the test manager URL from Automation Cloud and choose your project in the Default Project. Once connected, it is reflected with a green icon

Click Connect and log in using your Test Manager credentials.

Select your Default Project from the dropdown list.

Click OK to save changes.

Now, you will find the test cases that were part of the exercise, as well as the manual test cases here in Studio - in the Test Explorer

[IMAGE: Test Explorer panel in Studio]

Now, we will import the object repository library into this project

Click on Manage Packages from the top ribbon

Go to settings

Provide a unique name for the package source

Click on the ellipsis (...) button and browse to the custom location where the library was saved. Select the library and click Add.

You will find the custom library listed on the left panel along with other sources

The custom library appears alongside the defined sources.
