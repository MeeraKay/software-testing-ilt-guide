Autopilot Search

With the help of the Autopilot search, you can search any test object within a project using natural language.

If you are not sure what to search for, you can use one of the example search queries that Autopilot provides.
Additionally, after returning the results, Autopilot allows you to perform actions on the resulted objects.

Prompt Library

The Prompt Library within Test Manager provides a curated collection of predefined and custom prompts that guide the Autopilot feature. These prompts are used to shape the AI's behavior when generating test suggestions or analyzing requirements.

Predefined prompts address a variety of use cases, including but not limited to:
- End-to-End Flow Verification
- Rapid Test Idea Generation
- Elusive Issue Detection
- Boundary-Value Testing
- SAP Business Process Testing

These prompts serve as accelerators for generating relevant test scenarios or obtaining focused insights from requirements documentation.

Best Practices for Prompt Generation

1. Leverage Predefined Prompts
Start with the predefined prompts available in the prompt library. These are designed to help you quickly initiate tasks and guide Autopilot effectively. Reviewing and utilizing these can save time and provide a solid foundation for your instructions.

2. Customize for Your Needs
While predefined prompts are useful, take advantage of the ability to customize them according to your specific requirements. Tailoring prompts to your unique test cases or workflows can enhance the accuracy and relevance of the results Autopilot generates.

3. Be Clear and Concise
When creating custom prompts, ensure your instructions are clear and specific. Ambiguous prompts can lead to misinterpretations, so using straightforward language will help Autopilot understand your intent better.

4. Test and Iterate
After generating prompts, conduct tests to evaluate their effectiveness. Monitor the outcomes and adjust your prompts as necessary to refine the results and ensure they meet your expectations.

5. Document Effective Prompts
Keep a record of prompts that yield successful results. This documentation can serve as a reference for future projects, enabling you to build upon effective instructions and improve team efficiency.

AI-powered insights

What is it?

With this feature, Autopilot provides testers with actionable insights into test results without the need for prebuilt templates. The primary goal of the resulting 'test insights reports' is to help testers understand why test cases are failing by generating a report with Autopilot.

The report can include up to five sections, each containing multiple insights. For each insight in the report, select the icon displaying the number of test cases or click "Show" to view the affected related objects, such as test cases or test case logs, and search through them.

Detailed overview of identified issues

| Common Errors | Highlights the most common errors encountered during test executions. |
| Error Patterns | Categorizes errors and allows you to identify failure patterns based on them. This helps in easier troubleshooting and resolution. |
| Recommendations | Offers recommendations to prevent the errors encountered in the chosen test executions. Designed to guide your next steps in optimizing the stability of your test execution. |
