# Additional Exercises

To receive your **Diploma of Completion**, you must complete the following exercises. They're designed to validate your working knowledge of the concepts and skills covered during the training.

!!! example "Exercise: Academy Training Recommendation"
    ✅ Create a workflow that receives a topic as input (e.g. "RPA").

    ✅ Navigates to <a href="https://academy.uipath.com" target="_blank">UiPath Academy</a>.

    ✅ Searches for the topic on the `Courses` page.

    ✅ Opens the first suggested course.

    Create a test case that tests whether the suggestion was correct — verify the course name contains the searched topic.

!!! example "Exercise: Hash Check"
    ✅ You're given an Excel file containing the word "UiPath" hashed with multiple hashing methods.

    ✅ Using the data-driven method, check that for every hash method, the output matches the one returned by <a href="http://www.sha1-online.com/" target="_blank">sha1-online.com</a>.
